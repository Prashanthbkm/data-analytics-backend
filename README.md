# 📊 Data Analytics Dashboard

A full-stack analytics platform built during my internship at ACS Amossys Consultancy Services Pvt Ltd using Spring Boot, React.js, and PostgreSQL.

The platform processes and visualizes 6.2M+ transaction records with real-time filtering, KPI dashboards, interactive charts, export functionality, and AI-powered insights.

---

## 🚀 Features

* Real-time transaction filtering
* KPI dashboard with aggregate metrics
* Interactive charts and graph visualizations
* Dynamic table view with customizable columns
* Export reports to Excel and PDF
* Google Gemini AI chatbot integration
* Server-side pagination for large-scale datasets
* Optimized native SQL queries for faster performance
* Dockerized deployment

## ⚡ Challenges Faced

Handling 6.2M+ transaction records caused performance issues and slow response times during filtering operations.

### ✅ Solution

* Implemented server-side pagination
* Used optimized native SQL queries
* Reduced heavy data loading issues
* Improved application stability and response performance
